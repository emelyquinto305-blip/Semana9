Sistema operativo:
Es el software que administra el hardware y permite ejecutar aplicaciones. También controla los recursos del servidor para que funcione correctamente.

Node.js:
Es un entorno de ejecución que permite ejecutar aplicaciones JavaScript en el servidor. Se utiliza para crear servidores y APIs.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y las respuestas que recibirá el usuario.

Puerto:
Es el punto de comunicación por donde el servidor recibe las solicitudes de los clientes. Cada aplicación utiliza un puerto específico.

Logs:
Son archivos o registros donde se almacena la actividad del servidor. Ayudan a detectar errores y monitorear el funcionamiento del sistema.
